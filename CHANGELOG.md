# Changelog

## 0.1.0

Initial release.

- Standalone multi-LoRA loader with MODEL, CLIP, and trigger_words outputs.
- Per-row and global enable controls, shared or separate strengths, and missing-file warnings.
- Exact trigger words, effect labels, defaults, notes, and named presets.
- Explicit safetensors metadata suggestions with manual review.
- Local JSON library with conservative import, export, atomic writes, conflict detection, and backups.
- Workflow snapshots that preserve selections independently of later library edits.
- Searchable picker, collapsible rows, drag/keyboard reordering, and independent duplication.
- Local thumbnails with enlargement, visibility controls, and image safety limits.
- Python unit tests and JavaScript/DOM interaction tests.
- English interface, dialogs, tooltips, accessibility labels, and built-in error messages; user-authored text is preserved unchanged.
